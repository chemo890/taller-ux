
# Auditoría UX — Aplicación Mis Notas

## 1. Auditoría de las cinco heurísticas

| Heurística | Problema de la versión original | Solución propuesta |
|---|---|---|
| Visibilidad del estado del sistema | No se informa claramente cuando una nota se agrega o elimina. | Mostrar mensajes visibles después de cada acción. |
| Coincidencia con el mundo real | Los campos usan textos de ejemplo que desaparecen al escribir. | Incorporar etiquetas visibles para cada campo. |
| Control y libertad del usuario | Al eliminar una nota no existe forma de recuperarla. | Añadir una opción para deshacer la eliminación. |
| Consistencia y estándares | Los elementos tienen un estilo básico y poco uniforme. | Definir variables CSS y mantener un espaciado consistente. |
| Prevención de errores | El formulario no explica claramente cómo corregir una entrada vacía. | Validar los datos antes de agregar la nota. |

## 2. Leyes de diseño

- **Ley de Fitts:** los botones tendrán una altura mínima de 44 px para facilitar su selección.
- **Ley de Hick:** se priorizarán las acciones principales y se evitarán opciones innecesarias.
- **Ley de Miller:** se agruparán el formulario y las notas para facilitar la organización visual de la información.
